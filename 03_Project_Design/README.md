# 3. Project Design

## System Architecture

User
↓
EduGenie Web Interface
↓
FastAPI Backend
↓
AI Modules
↓
Google Gemini API
↓
AI Response
↓
User Interface

## Main Modules

1. Question & Answer
2. Explanation
3. Quiz Generation
4. Summarization
5. Learning Recommendations

## User Flow

1. User opens EduGenie.
2. User selects a feature.
3. User enters a question or content.
4. Backend processes the request.
5. AI generates the response.
6. Result is displayed to the user.
